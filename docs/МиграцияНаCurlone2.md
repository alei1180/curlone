# Миграция на curlone 2

curlone 2 несовместим с библиотечным API, интерфейсом командной строки и HTTP API версии 1. Перед обновлением
сохраните используемые команды и ожидаемый код, затем сравните их с результатом версии `2.0.0-alpha.1`.

## Что изменилось

| Область | Версия 1 | Версия 2 |
| --- | --- | --- |
| Библиотека | Несколько специализированных конвертеров | `КонвертерCURL` и единый результат |
| Командная строка | Команда передавалась корневому приложению | Подкоманда `curlone convert` |
| HTTP API | `/api`, `/api/v1`, `/api/v1/convert` | `POST /api/v2/convert` |
| Генераторы | Внутренние формирователи | Версионируемый SPI и реестр |
| Диагностика | Неоднородные ошибки | Машинные коды, ошибки и предупреждения |

## Подготовка

1. Найдите вызовы удалённых классов, команды без `convert` и запросы к HTTP API версии 1.
2. Зафиксируйте цель, язык кода и параметры каждого вызова.
3. Проверьте команды по [матрице возможностей](МатрицаВозможностейCURL.md).
4. Определите, допустимо ли продолжать работу при предупреждениях о потерях.

## Библиотечный API

Удалены `КонвертерКомандыCURL`, `КонсольныйКонвертерКомандыCURL`, `ПулКонвертеровКомандыCURL`,
`ГенераторПрограммногоКода1С` и `ГенераторПрограммногоКодаКоннекторHTTP`.

Новая точка входа:

```bsl
#Использовать curlone

Параметры = Новый ПараметрыКонвертацииCURL("curl https://example.com");
Параметры.Цель = ЦелиКонвертацииCURL.ПлатформенныйHTTP();
Параметры.Локаль = ЛокалиКонвертацииCURL.Русская();

Результат = Новый КонвертерCURL().Конвертировать(Параметры);

Если Результат.Успешно() Тогда
    Сообщить(Результат.Код());
Иначе
    Для Каждого ЭлементДиагностики Из Результат.Диагностика() Цикл
        Сообщить(ЭлементДиагностики.Сообщение);
    КонецЦикла;
КонецЕсли;
```

Команда принимает строку или массив аргументов. Цели имеют идентификаторы `1c` и `connector`, локали имеют коды
`ru` и `en`. Предупреждения доступны отдельно через `Предупреждения()` и вместе с ошибками через `Диагностика()`.

Подробности: [КонвертерCURL](КонвертерCURL.md),
[ПараметрыКонвертацииCURL](ПараметрыКонвертацииCURL.md) и
[РезультатКонвертацииCURL](РезультатКонвертацииCURL.md).

## Интерфейс командной строки

Добавьте подкоманду `convert`:

```shell
curlone convert "curl https://example.com"
curlone convert --target connector --locale en -- curl https://example.com
curlone convert --input command.txt --output result.bsl
echo "curl https://example.com" | curlone convert --format json
```

Опция `--command` отсутствует. Команда передаётся позиционно, после разделителя `--`, из файла или стандартного
ввода. Формат `json` возвращает единый объект и не записывает диагностику в поток ошибок.

Полный синтаксис и коды завершения приведены в [документации CLI](ИнтерфейсКоманднойСтроки.md).

## HTTP API

Маршруты версии 1 удалены. Новый запрос:

```http
POST /api/v2/convert
Content-Type: application/json

{
  "command": "curl https://example.com",
  "target": "1c",
  "locale": "ru",
  "generatorOptions": {
    "deserializeJsonResponse": false
  }
}
```

Ответ всегда содержит `success`, `target`, `code`, `errors` и `warnings`. Размер тела ограничен 65536 байтами.
При временном переполнении параллелизма возвращается состояние `503` и код `resilience.parallelism.rejected`.

Полный договор приведён в [документации HTTP API](HTTPAPI.md).

## Собственные генераторы

Генератор версии 2 реализует пять функций SPI: `Идентификатор`, `Наименование`, `ВерсияКонтракта`, `Возможности`
и `Сгенерировать`. Объект регистрируется до создания `КонвертерCURL`:

```bsl
Реестр = Новый РеестрГенераторовCURL;
Реестр.Зарегистрировать(Новый МойГенераторCURL);
Конвертер = Новый КонвертерCURL(Реестр);
```

Генератор получает готовый `КонтекстГенерацииКода`, не разбирает команду повторно и обязан поддерживать
одновременные вызовы. Подробности приведены в [контракте генератора](spi/ГенераторКодаCURL.md).

## Изменения поведения

- Представимая потеря создаёт предупреждение, а не ошибку.
- Непредставимое обязательное поведение останавливает генерацию.
- `--data @file` читает файл во время выполнения сформированного кода.
- В последовательности `--no-location --location` действует последняя опция.
- `-O` для URL без имени использует безопасное имя `curl_response`.
- Лишние `--upload-file` создают предупреждение `curlone.generator.option_ignored`.
- SOCKS5h, AWS Signature v4 и активный FTP воспроизводятся не полностью.

## Проверка после обновления

- Все команды вызываются через `curlone convert`.
- Библиотечные вызовы используют `КонвертерCURL` и проверяют `Успешно()`.
- HTTP-клиенты отправляют JSON только в `/api/v2/convert`.
- Обработчики различают ошибки и предупреждения.
- Критичные команды проверены для нужных целей и локалей.
- Собственные генераторы объявляют фактически поддерживаемые возможности SPI версии 1.
