# Документация curlone

curlone преобразует команды `curl` в код OneScript. Использовать конвертер можно из командной строки, через
HTTP API, в браузере или как библиотеку.

- [Интерфейс командной строки](ИнтерфейсКоманднойСтроки.md) - команда `convert`, входные данные и коды завершения
- [HTTP API](HTTPAPI.md) - запрос `POST /api/v2/convert` и структура ответа
