# Реестр генераторов CURL

`РеестрГенераторовCURL` регистрирует объекты SPI версии 1. Метод `Зарегистрировать()` проверяет отражением пять
экспортных функций, затем один раз читает метаданные и публикует запись только после полной проверки. Функция
генерации при регистрации не вызывается.

`Описания()` возвращает фиксированный массив в порядке регистрации. Служебный метод `Снимок()` возвращает
фиксированное соответствие, где каждому идентификатору сопоставлена фиксированная структура с полями `Описание`
и `Генератор`. Старый снимок не меняется после новой регистрации.

Регистрация и получение снимка предназначены для последовательной настройки приложения. Параллельная регистрация
не входит в контракт. Несовместимая версия имеет отдельный код ошибки, остальные нарушения SPI используют код
нарушения контракта генератора.
