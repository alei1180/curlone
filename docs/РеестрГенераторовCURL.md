# РеестрГенераторовCURL

Реестр проверяет и хранит пользовательские генераторы. Новый реестр пуст. Чтобы использовать его для конвертации,
зарегистрируйте генераторы до создания `КонвертерCURL`.

## Регистрация

```bsl
Реестр = Новый РеестрГенераторовCURL;
Реестр.Зарегистрировать(Новый МойГенераторCURL);

Конвертер = Новый КонвертерCURL(Реестр);
```

`Зарегистрировать(Генератор)` проверяет пять функций SPI, их сигнатуры и метаданные. Функция `Сгенерировать()` при
регистрации не вызывается. Метаданные читаются один раз и публикуются только после полной проверки.

Повторный идентификатор, неверная форма функций и недопустимые возможности приводят к
`curlone.generator.contract_violated`. Неподдерживаемая версия SPI приводит к
`curlone.generator.incompatible_contract`.

## Описания

```bsl
Для Каждого Описание Из Реестр.Описания() Цикл
    Сообщить(Описание.Идентификатор() + ": " + Описание.Наименование());
КонецЦикла;
```

`Описания()` возвращает `ФиксированныйМассив` в порядке регистрации.

## Параллельное выполнение

Настройка реестра выполняется последовательно до создания конвертера. Параллельная регистрация не входит в
контракт. Один зарегистрированный объект генератора может одновременно обслуживать несколько преобразований,
поэтому сам генератор обязан быть потокобезопасным.
