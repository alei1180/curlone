# ПараметрыКонвертацииCURL

Класс хранит исходную команду и изменяемые настройки одного вызова `КонвертерCURL.Конвертировать()`.

## Создание

```bsl
Параметры = Новый ПараметрыКонвертацииCURL(<Команда>);
```

`Команда` принимает непустую строку в нотации Bash, `Массив` или `ФиксированныйМассив` аргументов. Переданный массив
копируется, поэтому изменение его состава после создания параметров не меняет команду.

## Поля

| Поле | Тип | Значение по умолчанию | Описание |
| --- | --- | --- | --- |
| `Команда` | строка или массив | значение конструктора | Исходная команда |
| `Цель` | строка | `ЦелиКонвертацииCURL.ПлатформенныйHTTP()` | Идентификатор генератора |
| `Локаль` | строка | `ЛокалиКонвертацииCURL.Русская()` | Язык сформированного кода |
| `ФорматДесериализацииОтвета` | строка или `Неопределено` | `Неопределено` | Формат обработки HTTP-ответа |
| `ПараметрыГенератора` | `Соответствие` | пустое | Настройки внешнего генератора |

Поддерживаемые значения поля `ФорматДесериализацииОтвета` определены в модуле
`ФорматыДесериализацииОтветаCURL`. HTTP API передаёт это поле под именем
`generatorOptions.responseDeserializationFormat`.

## Пример Connector

```bsl
Параметры = Новый ПараметрыКонвертацииCURL("curl https://example.com");
Параметры.Цель = ЦелиКонвертацииCURL.КоннекторHTTP();
Параметры.Локаль = ЛокалиКонвертацииCURL.Английская();
Параметры.ФорматДесериализацииОтвета = ФорматыДесериализацииОтветаCURL.JSON();
```
