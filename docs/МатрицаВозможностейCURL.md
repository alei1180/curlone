# Матрица возможностей

Матрица показывает, насколько точно встроенные генераторы воспроизводят поведение curl. Источником истины служат
объявленные возможности генераторов и автоматические сценарии с проверкой полного текста кода.

## Обозначения

| Статус | Значение |
| --- | --- |
| Поддержано | Поведение представлено без известной потери |
| Приближённо | Код сформирован вместе с предупреждением |
| Ошибка | Выбранный генератор не может представить обязательное поведение |
| По значению | Результат зависит от значения, вычисляемого во время выполнения сформированного кода |

Отсутствие возможности в SPI не всегда останавливает преобразование. Если безопасное приближение существует,
curlone формирует код и явно сообщает о потере.

## Общая поддержка

| Группа | Возможности | `1c` | `connector` |
| --- | --- | --- | --- |
| Протоколы | HTTP, HTTPS | Поддержано | Поддержано |
| Операции | Несколько URL и `--next` | Поддержано | Поддержано |
| Запрос | Метод, заголовки, параметры URL | Поддержано | Поддержано |
| Тело | Данные, JSON, файл, составная форма | Поддержано | Поддержано |
| Аутентификация | Basic, NTLM, Negotiate, OAuth2 | Поддержано | Поддержано |
| Прокси | HTTP, учётные данные, Basic, NTLM | Поддержано | Поддержано |
| TLS | Сертификат клиента, файл УЦ, системное хранилище | Поддержано | Поддержано |
| Результат | Файл, имя из URL, каталог | Поддержано | Поддержано |
| Выражения | Переменные и отложенная классификация | Поддержано | Поддержано |

## Различия целей

| Возможность | `1c` | `connector` |
| --- | --- | --- |
| FTP и FTPS | Поддержано | Ошибка |
| Пассивный FTP | Поддержано | Ошибка |
| Активный FTP | Приближённо | Ошибка |
| Получение только имён | Поддержано | Приближённо |
| Удаление ранее заданного заголовка | Поддержано | Приближённо |
| Digest-аутентификация | Приближённо | Поддержано |
| Переход по перенаправлениям | Приближённо | Поддержано |

Цель `1c` объявляет 41 возможность, цель `connector` объявляет 38 возможностей.

## Общие приближения

Обе цели предупреждают о возможной потере для следующих групп:

- выбор способа аутентификации и AWS Signature v4;
- повторяющиеся заголовки и заголовки из файла или стандартного ввода;
- чтение данных из стандартного ввода;
- HTTPS- и SOCKS-прокси, а также Unix-сокет прокси;
- повторы, общее время выполнения и время соединения;
- значения, точный вид которых определяется только во время выполнения.

Ядро не читает файлы и стандартный ввод, указанные внутри команды curl. Оно передаёт генератору описание источника.
Сформированный код читает источник во время выполнения, если выбранная цель это поддерживает.

## Машинные коды

| Ситуация | Код |
| --- | --- |
| Возможность представлена приближённо | `curlone.generator.unsupported_capability` |
| Опция не влияет на сформированный код | `curlone.generator.option_ignored` |
| Значение преобразовано с потерями | `curlone.generator.lossy_conversion` |
| Обязательное поведение невозможно представить | `curlone.generator.unrepresentable_semantics` |
