# РезультатКонвертацииCURL

Класс представляет успешный или неуспешный результат одного преобразования. Ожидаемые проблемы команды находятся
в результате и не выбрасываются вызывающему коду.

## Проверка результата

```bsl
Если Результат.Успешно() Тогда
    Код = Результат.Код();
Иначе
    Ошибки = Результат.Ошибки();
КонецЕсли;
```

`Успешно()` возвращает `Истина`, когда код непустой и ошибки отсутствуют. Предупреждения не делают результат
неуспешным.

## Методы

| Метод | Возвращаемое значение | Описание |
| --- | --- | --- |
| `Успешно()` | `Булево` | Признак успешной генерации |
| `Код()` | `Строка` | Сформированный код или пустая строка |
| `Ошибки()` | `Массив` из `ИнформацияОбОшибке` | Копия списка ошибок |
| `Предупреждения()` | `Массив` из `ПредупреждениеКонвертацииCURL` | Копия списка предупреждений |
| `Диагностика()` | `Массив` из `Структура` | Безопасное единообразное представление диагностик |
| `ИдентификаторГенератора()` | `Строка` | Использованный или запрошенный идентификатор цели |

`Диагностика()` сначала возвращает ошибки, затем предупреждения. Каждый элемент содержит поля:

| Поле | Тип | Описание |
| --- | --- | --- |
| `Вид` | строка | `Ошибка` или `Предупреждение` |
| `Код` | строка | Стабильный машинный код |
| `Сообщение` | строка | Безопасный текст для пользователя |
| `ИдентификаторВозможности` | строка, `Неопределено` | Возможность генератора |
| `ИсходнаяОпция` | строка, `Неопределено` | Опция curl |
| `Позиция` | число, `Неопределено` | Позиция в исходной команде |
| `ИдентификаторГенератора` | строка, `Неопределено` | Целевой генератор |

## Неизменяемость

Конструктор копирует состав переданных массивов. Методы `Ошибки()` и `Предупреждения()` также возвращают новые
массивы. Сами элементы коллекций не копируются.
