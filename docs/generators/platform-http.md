# Платформенные HTTP и FTP

`ГенераторКодаПлатформыCURL` реализует SPI версии 1 с идентификатором `1c`.
Он получает готовые операции семантической модели и не разбирает исходную команду повторно.

При полном снимке возможностей операции преобразуются адаптером в описание запроса для существующего
формирователя. Это сохраняет полный текст кода, который выдавал прежний публичный конвертер.
При сокращённом снимке используется формирователь операции, учитывающий только переданные возможности.

Генератор не хранит состояние вызова. Перевод формируемого кода выполняется через i18n.
Формирование строк использует `КонструкторПрограммногоКода`.

## Параметры

Поддерживаются локали `ru` и `en`.

Параметр `ДесериализоватьОтветИзJSON` имеет тип `Булево` и по умолчанию равен `Ложь`.
Он включает прежний вариант чтения JSON из HTTP-ответа.

## Возможности

Генератор объявляет HTTP, HTTPS, FTP и FTPS, несколько операций, методы HTTP и FTP,
заголовки, данные, загрузку файлов, составную форму, файлы ввода, аутентификацию,
HTTP-прокси, TLS, выходные файлы, переменные и отложенную классификацию.

Необъявленные необязательные возможности дают предупреждение
`curlone.generator.unsupported_capability`. Неподдерживаемый протокол и вычисляемая возможность
дают ошибку `curlone.generator.unrepresentable_semantics`.

При использовании активного FTP через HTTP-прокси команда принимается. Без `--proxytunnel`
FTP-команды выполняет прокси, поэтому параметр активного режима не обязан приводить к отказу разбора.

## Матрица совместимости

[Матрица платформы](../../tests/fixtures/generation/МатрицаПлатформыCURL.json) содержит 148 сценариев,
полученных из `tests/ГенераторПрограммногоКода1С_test.os`. Каждый сценарий сравнивает полный текст кода.

При проверке исходных команд исправлены ошибки самих тестовых данных:

- пробелы в URL заменены на `%20`;
- закрыта пропущенная кавычка заголовка;
- шаблон имени загружаемого файла заключён в кавычки для защиты от раскрытия оболочкой;
- схема прокси `ftp://` заменена на поддерживаемую curl схему `http://`;
- значения `-F` с `<` заключены в кавычки, чтобы оболочка не воспринимала их как перенаправление ввода.

Ожидаемый код изменён только для исправленного URL с `%20`. Остальные исправления команд сохранили
прежний ожидаемый текст.
