# Платформенные HTTP и FTP

Платформенный генератор формирует код на стандартных типах платформы: `HTTPСоединение`, `HTTPЗапрос`,
`FTPСоединение` и `FTPФайл`.

## Выбор генератора

```shell
curlone convert --target 1c "curl https://example.com"
```

В библиотечном API:

```bsl
Параметры.Цель = ЦелиКонвертацииCURL.ПлатформенныйHTTP();
```

Идентификатор генератора: `1c`. Поддерживаемые локали: `ru` и `en`.

## Параметры

| Настройка | Тип | Значение по умолчанию | Назначение |
| --- | --- | --- | --- |
| `ФорматДесериализацииОтвета` | строка | `Неопределено` | Формат обработки тела HTTP-ответа |

Значение `ФорматыДесериализацииОтветаCURL.JSON()` включает разбор JSON. Для HTTP API этой настройке соответствует
`generatorOptions.responseDeserializationFormat`.

## Поддерживаемые сценарии

Генератор формирует код для HTTP, HTTPS, FTP и FTPS. Поддерживаются несколько операций, методы запроса, заголовки,
данные формы и JSON, загрузка файлов, составные формы, аутентификация, HTTP-прокси, сертификаты и запись результата
в файл.

Пассивный FTP поддерживается напрямую. Активный FTP формируется с предупреждением, потому что поведение платформы
может отличаться от curl. При использовании HTTP-прокси без `--proxytunnel` FTP-команду выполняет сам прокси.

## Ограничения

- Digest-аутентификация формируется приближённо.
- Выбор способа аутентификации, AWS Signature v4, SOCKS-прокси, повторы и таймауты могут отличаться от curl.
- Повторяющиеся заголовки теряют точный порядок или одно из значений.
- Источники из стандартного ввода нельзя воспроизвести без участия вызывающей программы.

Представимая потеря даёт предупреждение. Неподдерживаемый протокол или другая обязательная семантика останавливает
генерацию с ошибкой `curlone.generator.unrepresentable_semantics`.
