# Коннектор HTTP

`ГенераторКодаКоннектораCURL` реализует SPI версии 1 с идентификатором `connector`.
Он получает готовые операции семантической модели и не читает файлы во время генерации.

При полном снимке возможностей операции преобразуются адаптером в описание запроса для существующего
формирователя Connector. Это сохраняет полный текст кода прежнего публичного конвертера.
Сокращённый снимок обрабатывается формирователем операции с учётом переданных возможностей.

Генератор не хранит состояние вызова. Для перевода используется i18n, для сборки строк
используется `КонструкторПрограммногоКода`.

## Параметры

Поддерживаются локали `ru` и `en`.

`ДесериализоватьОтветИзJSON` имеет тип `Булево` и по умолчанию равен `Ложь`.
При значении `Истина` используются прежние методы Connector для получения JSON.

## Возможности и ограничения

Генератор объявляет HTTP и HTTPS, несколько операций, методы запроса, заголовки, данные,
загрузку файлов, составную форму, чтение файлов, аутентификацию, HTTP-прокси, TLS,
выходные файлы, переменные и отложенную классификацию.

FTP и FTPS блокируются как неподдерживаемые протоколы. Необъявленные необязательные возможности,
включая точную семантику перенаправлений, повторов и общего таймаута curl, дают предупреждение.
Параметры Connector для этих режимов формируются, но их поведение может отличаться от curl.

NTLM и Negotiate используют аутентификацию ОС Connector, в том числе без явного пользователя.

## Матрица совместимости

[Матрица Connector](../../tests/fixtures/generation/МатрицаКоннектораCURL.json) содержит 134 сценария,
полученных из `tests/ГенераторПрограммногоКодаКоннекторHTTP_test.os`.
Каждый сценарий сравнивает полный текст кода.

При проверке исходных команд исправлены ошибки самих тестовых данных:

- пробелы в URL заменены на `%20`;
- закрыта пропущенная кавычка заголовка;
- шаблон имени загружаемого файла заключён в кавычки;
- значения `-F` с `<` заключены в кавычки, чтобы оболочка не выполняла перенаправление ввода;
- для `--no-location --location` применено правило curl, по которому последняя опция имеет приоритет.

Ожидаемый код изменён для URL с `%20` и для последней пары опций перенаправления.
Остальные исправления команд сохранили прежний ожидаемый текст.
