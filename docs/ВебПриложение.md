# Веб-приложение

Веб-приложение предоставляет форму конвертации в браузере и HTTP API версии 2.

## Запуск

```shell
curlone serve
curlone serve --port 3333 --open
```

| Параметр | Назначение |
| --- | --- |
| `-p`, `--port` | Порт веб-сервера |
| `-o`, `--open` | Открыть страницу в браузере после запуска |

Справка доступна через `curlone serve --help`.

## Настройка

Для постоянной настройки веб-приложения создайте файл `autumn-properties.json` в каталоге, из которого запускается команда `curlone serve`.

**Доступные параметры:**

| Параметр                                                     | Описание                                                     | Значение по умолчанию |
| ------------------------------------------------------------ | ------------------------------------------------------------ | --------------------- |
| `curlone.web.Порт`                                           | Порт, на котором запускается веб-сервер                      | `3333`                |
| `curlone.web.МаксимальноеКоличествоОдновременныхКонвертаций` | Максимальное количество одновременно выполняемых конвертаций | `50`                  |

Пример файла `autumn-properties.json`:

```json
{
  "curlone": {
    "web": {
      "Порт": 8080,
      "МаксимальноеКоличествоОдновременныхКонвертаций": 50
    }
  }
}
```

Параметр командной строки `--port` имеет приоритет над значением, указанным в `autumn-properties.json`. Например:

```bash
curlone serve --port 4444
```

В этом случае сервер будет запущен на порту `4444` независимо от значения `curlone.web.Порт` в файле конфигурации.
## Конвертация

1. Вставьте команду `curl` в нотации Bash.
2. Выберите цель `1С` или `Connector`.
3. При необходимости включите разбор JSON-ответа.
4. Выберите язык кода `ru` или `en`.
5. Нажмите «Конвертировать».

Сформированный код подсвечивается в браузере. Кнопка «Скопировать» помещает его в буфер обмена. Изменение цели,
языка или параметра JSON повторяет преобразование заполненной команды.

Ошибки и предупреждения выводятся раздельно. Предупреждение означает, что код сформирован, но часть поведения curl
воспроизведена приблизительно или проигнорирована.

## HTTP API

Форма отправляет запросы только в `POST /api/v2/convert`. Схема запроса и ответа описана в
[документации HTTP API](HTTPAPI.md).
