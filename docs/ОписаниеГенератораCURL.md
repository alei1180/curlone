# ОписаниеГенератораCURL

Неизменяемый снимок метаданных зарегистрированного генератора. Описания возвращает
[`РеестрГенераторовCURL.Описания()`](РеестрГенераторовCURL.md#описания).

## Методы

| Метод | Возвращаемое значение | Описание |
| --- | --- | --- |
| `Идентификатор()` | `Строка` | Уникальный идентификатор цели |
| `Наименование()` | `Строка` | Отображаемое наименование |
| `ВерсияКонтракта()` | `Число` | Версия SPI |
| `Возможности()` | `ФиксированныйМассив` из `Строка` | Объявленные возможности |

Реестр копирует список возможностей во время регистрации. Изменение исходного массива или последующего состояния
генератора не меняет описание.
