# Описание генератора CURL

`ОписаниеГенератораCURL` хранит идентификатор, наименование, версию контракта и фиксированный массив возможностей.
Методы `Идентификатор()`, `Наименование()`, `ВерсияКонтракта()` и `Возможности()` предоставляют значения только для
чтения. Реестр создаёт независимую копию списка возможностей, поэтому последующее состояние объекта генератора не
изменяет зарегистрированное описание.
