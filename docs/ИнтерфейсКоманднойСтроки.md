# Интерфейс командной строки

Команда `curlone convert` преобразует одну команду `curl` в программный код. Исходная команда должна использовать
нотацию Bash.

## Использование

```text
curlone convert [ПАРАМЕТРЫ] [КОМАНДА]
curlone convert [ПАРАМЕТРЫ] -- curl [АРГУМЕНТЫ]
```

Команду можно передать четырьмя способами:

```shell
curlone convert "curl https://example.com"
curlone convert -- curl -s https://example.com
curlone convert --input command.txt
echo "curl https://example.com" | curlone convert --input -
```

Разделитель `--` завершает параметры curlone. Используйте его, когда аргументы `curl` передаются отдельно или
начинаются с дефиса.

## Параметры

| Параметр | Значения | Значение по умолчанию |
| --- | --- | --- |
| `-t`, `--target` | `1c`, `connector` | `1c` |
| `-l`, `--locale` | `ru`, `en` | `ru` |
| `-f`, `--format` | `text`, `json` | `text` |
| `-i`, `--input` | путь к файлу или `-` | стандартный ввод при отсутствии команды |
| `-o`, `--output` | путь к файлу или `-` | стандартный вывод |
| `--fail-on-warning` | без значения | выключен |

Позиционная команда, `--input` и аргументы после `--` являются взаимоисключающими источниками. Пустой стандартный
ввод приводит к ошибке обязательного аргумента.

## Вывод

В формате `text` сформированный код записывается в стандартный вывод, а ошибки и предупреждения в поток ошибок.
Если задан `--output`, код записывается в указанный файл. Ошибка конвертации не создаёт и не изменяет файл результата.

В формате `json` стандартный вывод содержит объект с полями `success`, `target`, `code`, `errors` и `warnings`.
Поток ошибок остаётся пустым. Параметр `--output` направляет этот объект в файл.

## Коды завершения

| Код | Значение |
| ---: | --- |
| `0` | Код сформирован |
| `1` | Внутренняя ошибка приложения |
| `2` | Неверные параметры командной строки |
| `3` | Команда принята, но код сформировать невозможно |
| `4` | Неизвестная цель или нарушение контракта генератора |
| `5` | Получены предупреждения при включённом `--fail-on-warning` |

## Справка

```shell
curlone --help
curlone convert --help
curlone --version
```
