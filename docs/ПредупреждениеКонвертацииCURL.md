# ПредупреждениеКонвертацииCURL

Предупреждение сообщает, что код сформирован, но часть поведения curl проигнорирована или представлена
приблизительно.

## Методы

| Метод | Возвращаемое значение | Описание |
| --- | --- | --- |
| `Код()` | `Строка` | Машинный код предупреждения |
| `Сообщение()` | `Строка` | Текст для пользователя |
| `ИдентификаторВозможности()` | `Строка` | Код возможности или пустая строка |
| `ИсходнаяОпция()` | `Строка` | Исходная опция или пустая строка |
| `Позиция()` | `Число` | Позиция опции или `-1` |
| `ИдентификаторГенератора()` | `Строка` | Целевой генератор или пустая строка |

## Машинные коды

| Функция `КодыПредупрежденийCurlone` | Код |
| --- | --- |
| `НеподдерживаемаяВозможность()` | `curlone.generator.unsupported_capability` |
| `ОпцияПроигнорирована()` | `curlone.generator.option_ignored` |
| `ПреобразованиеСПотерями()` | `curlone.generator.lossy_conversion` |

Обрабатывайте предупреждения по машинному коду. Текст сообщения может меняться и переводиться.

## Пример

```bsl
Для Каждого Предупреждение Из Результат.Предупреждения() Цикл
    Сообщить(Предупреждение.Сообщение());
КонецЦикла;
```
