# Цели и локали конвертации

Публичные модули предоставляют именованные значения для настройки `ПараметрыКонвертацииCURL`. Использование функций
вместо строковых литералов защищает вызывающий код от опечаток.

## ЦелиКонвертацииCURL

| Функция | Значение | Результат |
| --- | --- | --- |
| `ПлатформенныйHTTP()` | `1c` | Код для платформенных HTTP и FTP |
| `КоннекторHTTP()` | `connector` | Код для библиотеки Connector |

## ЛокалиКонвертацииCURL

| Функция | Значение | Результат |
| --- | --- | --- |
| `Русская()` | `ru` | Русские служебные имена переменных и диагностика |
| `Английская()` | `en` | Английские служебные имена переменных и диагностика |

Переменные из команды curl сохраняют свои имена, если они свободны: `$HOST` становится `HOST`.
При совпадении с ключевым словом языка или зарезервированным служебным именем добавляется префикс `CURL_`:
например, `$If` становится `CURL_If`, а `$Headers` становится `CURL_Headers`.
Служебные имена генераторов зарезервированы в обеих локалях, включая варианты с числовыми суффиксами.
При совпадении с уже назначенным пользовательским именем без учёта регистра добавляется числовой суффикс:
`$TOKEN` и `$token` становятся `TOKEN` и `token_2` по порядку первого использования.
Повторное использование одной переменной сохраняет назначенное имя.

## Пример

```bsl
Параметры.Цель = ЦелиКонвертацииCURL.КоннекторHTTP();
Параметры.Локаль = ЛокалиКонвертацииCURL.Английская();
```

В HTTP API и интерфейсе командной строки используются строковые значения из таблиц.
