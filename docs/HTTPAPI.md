# HTTP API

HTTP API преобразует команду `curl` тем же конвейером, что библиотека и интерфейс командной строки. Маршрут версии 2:

```text
POST /api/v2/convert
Content-Type: application/json
```

Размер тела запроса ограничен 65536 байтами.

## Запрос

```json
{
  "command": "curl https://example.com",
  "target": "1c",
  "locale": "ru",
  "generatorOptions": {
    "deserializeJsonResponse": false
  }
}
```

| Поле | Тип | Обязательное | Значение по умолчанию |
| --- | --- | --- | --- |
| `command` | строка | да | нет |
| `target` | `1c` или `connector` | нет | `1c` |
| `locale` | `ru` или `en` | нет | `ru` |
| `generatorOptions` | объект | нет | `{}` |
| `generatorOptions.deserializeJsonResponse` | булево | нет | `false` |

Неизвестные поля не допускаются.

## Ответ

```json
{
  "success": true,
  "target": "1c",
  "code": "Сформированный код",
  "errors": [],
  "warnings": []
}
```

Ответ всегда содержит все пять полей. При ошибке `success` равен `false`, а `code` содержит пустую строку.

Элемент `errors` содержит `code`, `message` и `position`. Элемент `warnings` дополнительно содержит `capability`,
`option` и `target`. Позиция отсчитывается с единицы и может быть `null`, если она неизвестна.

## Состояния HTTP

| Состояние | Причина |
| ---: | --- |
| `200` | Запрос обработан, в том числе с предупреждениями |
| `400` | Неверный JSON или параметры запроса |
| `405` | Использован метод, отличный от `POST` |
| `413` | Превышен допустимый размер тела |
| `415` | Неверный `Content-Type` |
| `422` | Команду невозможно преобразовать |
| `500` | Внутренняя ошибка |
| `503` | Сервис временно перегружен |

При переполнении ограничения параллелизма ответ `503` содержит код `resilience.parallelism.rejected`.

## OpenAPI

После запуска приложения схема доступна по адресу `/api/v2/openapi.json`.
