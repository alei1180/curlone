# КонвертерCURL

`КонвертерCURL` является основной точкой входа библиотечного API. Класс преобразует команду и возвращает
[`РезультатКонвертацииCURL`](РезультатКонвертацииCURL.md), не выбрасывая ожидаемые ошибки разбора и генерации.

## Создание

```bsl
Конвертер = Новый КонвертерCURL(<Реестр = Неопределено>);
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| `Реестр` | `РеестрГенераторовCURL`, `Неопределено` | Пользовательский реестр или встроенные генераторы |

Если реестр не передан, регистрируются цели `1c` и `connector`. Переданный пользователем реестр используется без
добавления встроенных генераторов.

Конструктор выбрасывает `argument.invalid_type`, если реестр имеет неверный тип.

## Конвертировать

```bsl
Результат = Конвертер.Конвертировать(<Параметры>);
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| `Параметры` | `ПараметрыКонвертацииCURL` | Команда и настройки конвертации |

Метод возвращает `РезультатКонвертацииCURL`. Для параметра неверного типа выбрасывается `argument.invalid_type`.

## Пример

```bsl
#Использовать curlone

Параметры = Новый ПараметрыКонвертацииCURL("curl https://example.com");
Результат = Новый КонвертерCURL().Конвертировать(Параметры);

Если Результат.Успешно() Тогда
    Сообщить(Результат.Код());
Иначе
    Для Каждого ЭлементДиагностики Из Результат.Диагностика() Цикл
        Сообщить(ЭлементДиагностики.Сообщение);
    КонецЦикла;
КонецЕсли;
```
