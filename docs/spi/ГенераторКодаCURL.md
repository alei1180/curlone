# SPI генератора кода CURL

`ГенераторКодаCURL` задаёт контракт стороннего генератора. Наследовать общий базовый класс не требуется:
реестр проверяет экспортные функции и их точные сигнатуры. Регистр имён функций не влияет на совместимость.

## Обязательные функции

```bsl
Функция Идентификатор() Экспорт
Функция Наименование() Экспорт
Функция ВерсияКонтракта() Экспорт
Функция Возможности() Экспорт
Функция Сгенерировать(КонтекстГенерацииКода) Экспорт
```

`Идентификатор()` возвращает непустую строку без внешних пробелов. Идентификаторы целей регистрозависимы.
`Наименование()` возвращает непустую строку для отображения. `ВерсияКонтракта()` возвращает число `1`.
`Возможности()` возвращает фиксированный массив уникальных строк из [каталога](ВозможностиГенераторовCURL.md).
Реестр читает каждое значение один раз и фиксирует метаданные; пробная генерация при регистрации не выполняется.

`Сгенерировать(Контекст)` получает всю успешную команду одним вызовом и возвращает непустую строку кода.
Пробельная строка или результат другого типа нарушают контракт. Форматирование успешного кода сохраняется.

## Контекст и возможности

[Контекст генерации](КонтекстГенерацииКода.md) содержит неизменяемые модели операций с методами чтения,
идентификатор цели, локаль, параметры и зарегистрированные возможности. Конструктор принимает пять аргументов:

```bsl
Новый КонтекстГенерацииКода(
    Операции,
    Локаль,
    ПараметрыГенератора,
    ИдентификаторГенератора,
    ВозможностиГенератора)
```

Генератор использует `Контекст.ВозможностиГенератора()`, включая проверки в выпускаемом целевом коде.
Изменение ответа собственной функции `Возможности()` после регистрации не меняет этот снимок.
Генератор получает исходные модели операций семантического слоя, их вложенные модели и источники
из синтаксического слоя. Они передаются по ссылке; их методы чтения описаны в контракте контекста.
Повторный разбор команды не требуется.

Параметры генератора также передаются по ссылке, без копирования и фиксации. Генератор может изменять
изменяемые контейнеры и объекты параметров; эти изменения видны вызывающему коду.
Переданные фиксированные контейнеры сохраняют свои ограничения на изменение.

## Ошибки, допустимые потери и параллельные вызовы

Ядро проверяет обязательные возможности до генерации и возвращает предупреждения о допустимых потерях.
Генератор документирует применяемое приближение и использует одинаковые правила для литерального значения
и соответствующей ветви после вычисления. Неактивные части модели не вычисляются, хотя сохраняются в контексте.
Подробные правила активности и внешних источников приведены в [описании возможностей](ВозможностиГенераторовCURL.md).

Нарушение формы SPI или результата даёт `curlone.generator.contract_violated`.
Числовая несовместимая версия даёт `curlone.generator.incompatible_contract`.
Исключение генератора оборачивается в `curlone.generator.failed`; исходная причина сохраняется отдельно
от безопасной пользовательской диагностики. Собственные неожиданные ошибки ядра имеют стандартный код
`internal.invariant_violation`. Предупреждения анализа сохраняются при ошибке генератора.

Один зарегистрированный объект может вызываться одновременно. Данные конкретного вызова нужно хранить локально.
Общее изменяемое состояние генератора защищается с помощью `БлокировкаРесурса`.
Если несколько вызовов используют одни и те же изменяемые параметры, доступ к ним должен быть согласован
вызывающим кодом и генератором. Сервис не создаёт независимых копий параметров и не синхронизирует их изменение.
Сервис сохраняет снимок реестра при создании, поэтому последующие регистрации не меняют его состав целей.
Локаль передаётся генератору как есть; сервис не проверяет её значение. Стандартные коды `ru` и `en`
определены в `ЛокалиКонвертацииCURL`. Обработку поддерживаемых локалей определяет генератор.
При неизвестной цели результат сохраняет запрошенный строковый идентификатор.

Конструктор `СервисКонвертацииCURL` принимает реестр генераторов. После успешного анализа сервис создаёт
`КонтекстГенерацииКода` напрямую. Неожиданная ошибка создания контекста сохраняет предупреждения анализа
и возвращает `internal.invariant_violation`; генератор после отказа не вызывается.

Публичный пример: `tests/spi/Классы/СтороннийГенераторДляТестов.os`.
Регистрация и получение описаний рассмотрены в [документации реестра](../РеестрГенераторовCURL.md).
