# КонтекстГенерацииКода

Публичные данные одного вызова генератора SPI версии 1.
Контекст содержит все операции команды, локаль, параметры и зарегистрированные возможности выбранной цели.

## Создание

```bsl
Новый КонтекстГенерацииКода(
    Операции,
    Локаль,
    ПараметрыГенератора,
    ИдентификаторГенератора,
    ВозможностиГенератора,
    ФорматДесериализацииОтвета = Неопределено
)
```

| Параметр | Тип и назначение |
| --- | --- |
| `Операции` | Массив или фиксированный массив моделей ОперацияПередачиCURL |
| `Локаль` | Строка, код локали; стандартные коды определены в `ЛокалиКонвертацииCURL` |
| `ПараметрыГенератора` | Соответствие или фиксированное соответствие; ключи и значения определяет генератор |
| `ИдентификаторГенератора` | Строка, идентификатор выбранной цели |
| `ВозможностиГенератора` | Фиксированный массив уникальных строковых идентификаторов из каталога возможностей |
| `ФорматДесериализацииОтвета` | Строка из `ФорматыДесериализацииОтветаCURL` или `Неопределено` |

Первые пять параметров обязательны. Пустые операции, параметры и возможности допустимы при непосредственном создании.
Сервис передаёт весь набор возможностей зарегистрированного описания, использованный анализатором.

Контекст независимо копирует контейнеры операций и параметров генератора и предоставляет их в фиксированном виде.
Произвольные объекты внутри параметров сохраняются по ссылке. Общие и циклические ссылки коллекций сохраняются.

Локаль сохраняется без проверки и преобразования. Поддерживаемые значения и их обработку определяет генератор.

## Методы

| Сигнатура | Возвращаемое значение |
| --- | --- |
| `Операции()` | Независимый фиксированный массив ОперацияПередачиCURL |
| `Локаль()` | Строка, локаль генерируемого кода |
| `ПараметрыГенератора()` | Независимое фиксированное соответствие |
| `ФорматДесериализацииОтвета()` | Строка формата или `Неопределено` |
| `ИдентификаторГенератора()` | Строка, идентификатор цели |
| `ВозможностиГенератора()` | Независимый фиксированный массив зарегистрированных возможностей |

Генератор строит проверки целевого кода по `ВозможностиГенератора()` контекста.
Он не перечитывает собственный метод `Возможности()` и не использует изменяемый набор взамен снимка.
Методы чтения не изменяют состояние и не выбрасывают ожидаемых ошибок.

## Пример

```bsl
Возможности = Новый Массив;
Возможности.Добавить("protocol.https");
Параметры = Новый Соответствие;
Параметры.Вставить("Отступ", 4);
Контекст = Новый КонтекстГенерацииКода(
    Новый Массив,
    ЛокалиКонвертацииCURL.Русская(),
    Параметры,
    "example",
    Новый ФиксированныйМассив(Возможности)
);
Сообщить(Контекст.ВозможностиГенератора()[0]); // protocol.https
```

## Модели операций

Ниже перечислены классы моделей и их методы чтения. Модели и вложенные коллекции неизменяемы.
Методы моделей входят в контракт генератора. Порядок и повторения элементов сохраняются.
Отсутствующие значения представлены `Неопределено`.
Исходные значения запроса и токены могут содержать секреты; весь контекст не предназначен для журналирования.

```bsl
Для Каждого Операция Из Контекст.Операции() Цикл
    Адрес = Операция.Ресурс().АдресДляВыполнения();
    Если Адрес.ЯвляетсяЛитералом() Тогда
        ЛитеральныйАдрес = Адрес.ЛитеральноеЗначение();
    КонецЕсли;
КонецЦикла;
```

### Источник

`Источник()` возвращает исходный `ЭлементРазобраннойКомандыCURL` либо `ТокенКомандыCURL`
(у выражений), а в оговорённых необязательных полях допускается `Неопределено`.
Элемент предоставляет `ИсходныйТокен()`, `ОписаниеОпции()`, `ТокенОпции()`, `ТокенЗначения()` и `ТокенURL()`.
Каноническое имя опции доступно через `ОписаниеОпции().КаноническоеИмя()`, если описание присутствует.

Токен предоставляет `Значение()`, `ИсходноеПредставление()`, `Фрагменты()`, `Позиция()`,
`ПозицияВИсходнойСтроке()` и `ПозицияВАргументе()`. Позиции сохраняют нумерацию синтаксического этапа.
Источник больше не заменяется сокращённой структурой. Генератор получает исходные данные команды;
публичные диагностические сообщения по-прежнему должны исключать секреты.

## Связанные сущности

`ЧастьСтрокиЗапросаCURL.РежимИсточника()` сохраняет режим исходной части тела при `--get`.
В частности, `text_file_without_crlf_nul` требует удаления CR, LF и NUL из файла,
а `binary_file` сохраняет его байты. Последний необязательный параметр конструктора
`РежимИсточника` позволяет передать это различие без повторного разбора опции.
