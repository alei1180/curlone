# КодыОшибокCurlone

Публичный модуль предоставляет стабильные машинные коды ошибок curlone. Все функции вызываются без параметров
и возвращают `Строка`. Код позволяет обрабатывать ошибку независимо от текста сообщения.

## Использование

```bsl
Если ДиагностикаОшибок.Содержит(Ошибка, КодыОшибокCurlone.НеУказанURL()) Тогда
    // Предложить указать адрес передачи.
КонецЕсли;
```

## Поведение

Функции не создают ошибки и не выполняют анализ команды. Синтаксические ошибки обозначают нарушения формы команды,
семантические ошибки обозначают недопустимое сочетание или значение известных опций.

`НеУказанURL()` обозначает группу без URL, в том числе пустую группу у `--next`.
`НеподдерживаемаяОпция()` отличается от `НеизвестнаяОпция()`: имя известно каталогу, но его семантика не поддержана.
`НедопустимыйURL()` обозначает неразбираемый адрес; `НедопустимоеЗначениеОпции()` обозначает неверное значение опции.
`НесопоставленнаяОпцияURL()` обозначает лишний элемент позиционной очереди результата или загрузки.

`КонфликтТелаЗапроса()` обозначает несовместимые виды тела. `КонфликтРежимаЗапроса()` обозначает сочетание
`--head` с неперенесённым телом или загрузкой. `КонфликтСоединения()` обозначает активный FTP вместе с прокси.

Источники `--url @file`, `--url @-` и активные шаблоны URL или загрузки могут изменить количество передач.
Они возвращают `НеподдерживаемыйИсточникНесколькихПередач()` при интерпретации и
`НеподдерживаемыйМатериализованныйИсточникНесколькихПередач()` после подстановки переменных.
Остальные неверные вычисленные значения обозначаются `НедопустимоеМатериализованноеЗначение()`.

Фабрика семантических ошибок сохраняет позиции аргумента, символа исходной строки и символа аргумента.
Для конца команды все три позиции равны `-1`. Представление значения заменяется на `<значение скрыто>`.
Разрешены только канонические имена булевых опций без параметров, `--next` и отдельный `--`.
URL, заголовки, пути, учётные данные и имена переменных скрываются целиком. Вложенные ошибки разбора URL
не включаются в диагностику.

Ожидаемые ошибки находятся в результате интерпретации. При наличии ошибок описание выполнения отсутствует.
Нарушения типов аргументов и внутренних контрактов используют стандартные коды пакета `errors`:
`argument.invalid_type` и `internal.invariant_violation`.
