# КодыОшибокCurlone

Публичный модуль возвращает стабильные машинные коды ошибок curlone. Все функции вызываются без параметров и
возвращают `Строка`. Текст сообщения предназначен для человека и может меняться, программная обработка должна
использовать код.

## Использование

```bsl
Если ДиагностикаОшибок.Содержит(Ошибка, КодыОшибокCurlone.НеУказанURL()) Тогда
    Сообщить("Укажите адрес запроса");
КонецЕсли;
```

## Синтаксис команды

| Функция | Код |
| --- | --- |
| `ТребуетсяCurl()` | `curlone.command.curl_required` |
| `НезакрытаяКавычка()` | `curlone.command.unclosed_quote` |
| `НеподдерживаемыйСинтаксисОболочки()` | `curlone.command.unsupported_shell_syntax` |
| `НеизвестнаяОпция()` | `curlone.command.unknown_option` |
| `ТребуетсяЗначениеОпции()` | `curlone.command.option_value_required` |
| `ЗначениеОпцииНеДопускается()` | `curlone.command.option_value_not_allowed` |
| `НеУказанURL()` | `curlone.command.url_required` |
| `НеподдерживаемаяОпция()` | `curlone.command.unsupported_option` |
| `НедопустимыйURL()` | `curlone.command.invalid_url` |
| `НедопустимоеЗначениеОпции()` | `curlone.command.invalid_option_value` |
| `НесопоставленнаяОпцияURL()` | `curlone.command.unmatched_per_url_option` |
| `КонфликтТелаЗапроса()` | `curlone.command.conflicting_body` |
| `КонфликтРежимаЗапроса()` | `curlone.command.conflicting_request_mode` |
| `КонфликтСоединения()` | `curlone.command.conflicting_connection_options` |
| `НеподдерживаемыйИсточникНесколькихПередач()` | `curlone.command.unsupported_multiple_transfer_source` |

`НеизвестнаяОпция()` означает, что имени нет в каталоге curl. `НеподдерживаемаяОпция()` означает, что имя известно,
но его семантика ещё не реализована.

## Вычисляемые значения

| Функция | Код |
| --- | --- |
| `НедопустимоеМатериализованноеЗначение()` | `curlone.runtime.invalid_materialized_value` |
| `НеподдерживаемыйМатериализованныйИсточникНесколькихПередач()` | `curlone.runtime.unsupported_multiple_transfer_source` |

Эти ошибки возникают, когда значение файла, стандартного ввода или выражения становится известно только во время
выполнения сформированного кода и оказывается недопустимым.

## Генераторы

| Функция | Код |
| --- | --- |
| `НепредставимаяСемантикаГенератора()` | `curlone.generator.unrepresentable_semantics` |
| `НеизвестныйГенератор()` | `curlone.generator.unknown` |
| `ОшибкаГенератора()` | `curlone.generator.failed` |
| `НарушенКонтрактГенератора()` | `curlone.generator.contract_violated` |
| `НесовместимаяВерсияКонтрактаГенератора()` | `curlone.generator.incompatible_contract` |

Непредставимая семантика обнаруживается до вызова генератора. Исключение внутри стороннего генератора получает код
`curlone.generator.failed`, при этом исходная причина сохраняется в цепочке ошибки.

## Безопасность диагностики

Диагностика не раскрывает URL, заголовки, пути, учётные данные и значения переменных. Вместо исходного значения
используется `<значение скрыто>`. Позиция ошибки сохраняется отдельно и отсчитывается с единицы.

Ошибки типов публичного API и нарушения внутренних инвариантов используют стандартные коды библиотеки `errors`,
например `argument.invalid_type` и `internal.invariant_violation`.
